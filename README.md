# CyberRoadmap — Telegram Mini App

v0.2 — исправленная standalone-версия.

## Что есть
- Dashboard
- Roadmap на 26 недель
- Реальные checkbox
- Поиск
- Сегодня
- Заметки
- Сохранение прогресса в localStorage
- Адаптивный дизайн для ПК и телефона
- Подготовка к Telegram WebApp API

## GitHub Pages
Включить Settings → Pages → Deploy from a branch → main → / (root).

## Telegram
После публикации подключить URL как Main Mini App через @BotFather.

Токен бота не хранить в frontend и не публиковать в репозитории.
