# CyberRoadmap v1

Полноценная standalone-версия личного трекера обучения Information Security.

## Что внутри
- Dashboard с прогрессом, XP и уровнями
- 26-недельный roadmap
- 104 практические задачи
- чекбоксы и локальное сохранение
- поиск по roadmap
- вкладка «Сегодня»
- заметки
- экспорт прогресса
- адаптивный интерфейс для ПК и телефона
- Telegram WebApp SDK уже подключён

## Публикация
GitHub Pages: загрузи `index.html`, `styles.css`, `app.js`, `README.md` в корень репозитория.

Следующий этап: подключение к Telegram Bot API и серверное хранилище прогресса, чтобы данные синхронизировались между ПК и телефоном.
