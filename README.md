# CyberRoadmap — Telegram Mini App

Личный трекер обучения по информационной безопасности. Mobile-first, адаптирован под Telegram Desktop и телефон.

## Что уже есть
- 26-недельный roadmap из текущего плана.
- Главная с общим прогрессом и прогрессом по уровням.
- Roadmap с поиском.
- Реальные чекбоксы задач.
- Страница недели с теорией, практикой и заметкой.
- Редактирование задач и добавление собственных.
- Личные заметки.
- Telegram theme integration.
- Telegram CloudStorage при запуске внутри Telegram + localStorage fallback.
- Haptic feedback на мобильных клиентах.

## Важно
Это статическая версия без внешнего backend. Для одного пользователя этого достаточно: Telegram CloudStorage хранит данные для конкретного пользователя и бота. Telegram сейчас разрешает до 1024 ключей CloudStorage на пользователя, а значение одного ключа — до 4096 символов.

## Как запустить локально
Нужен Node.js 18+.

```bash
npx serve .
```

Для настоящего Telegram Mini App URL должен быть доступен по HTTPS. Для бесплатного размещения можно использовать Vercel, Netlify, GitHub Pages или Cloudflare Pages. После публикации URL указывается в @BotFather при настройке Main Mini App.

## Как подключить к Telegram
1. Открой @BotFather.
2. Создай нового бота через /newbot.
3. В настройках бота выбери Configure Mini App / Main Mini App.
4. Укажи публичный HTTPS URL этой папки после деплоя.
5. Настрой Menu Button, если хочешь кнопку «Открыть приложение» прямо в чате.

Токен бота для этой версии frontend не нужен и его нельзя передавать в чат. Если позже добавим backend/уведомления, токен хранится только как секретная переменная на сервере.
